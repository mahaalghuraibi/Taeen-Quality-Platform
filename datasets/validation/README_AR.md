# مجموعة بيانات التحقق من الدقة — عين الجودة

> ضع هنا صور اختبار حقيقية من كاميرات المطعم للتحقق من دقة نماذج YOLO.

## البنية

```
datasets/validation/
├── ppe/                  # نموذج معدات الحماية / الشخص
│   ├── no_mask/          # صور: شخص بدون كمامة  (مخالفة متوقعة)
│   ├── mask_ok/          # صور: شخص يرتدي كمامة (سليم)
│   ├── no_gloves/        # بدون قفازات (مخالفة)
│   ├── gloves_ok/        # يرتدي قفازات (سليم)
│   ├── no_headcover/     # بدون غطاء رأس (مخالفة)
│   ├── headcover_ok/     # يرتدي غطاء رأس (سليم)
│   ├── improper_uniform/ # زي غير مطابق (مخالفة)
│   └── uniform_ok/       # زي مطابق (سليم)
└── environment/          # نموذج البيئة / المكان
    ├── wet_floor/        # أرضية مبللة (مخالفة)
    ├── dry_floor/        # أرضية جافة (سليم)
    ├── trash_on_floor/   # نفايات على الأرض (مخالفة)
    ├── clean_floor/      # أرضية نظيفة (سليم)
    ├── unclean_area/     # منطقة غير نظيفة (مخالفة)
    ├── clean_area/       # منطقة نظيفة (سليم)
    ├── blocked_path/     # ممر مسدود (مخالفة)
    ├── clear_path/       # ممر سالك (سليم)
    ├── unsafe_area/      # منطقة غير آمنة (مخالفة)
    └── safe_area/        # منطقة آمنة (سليم)
```

## قواعد مهمة

- كل مجلد "مخالفة" يحتوي صوراً يجب أن **يكتشفها** النموذج.
- كل مجلد "سليم" (`*_ok`, `dry_floor`, `clean_*`, `clear_path`, `safe_area`) يحتوي صوراً يجب ألّا يطلق فيها النموذج إنذاراً (لقياس الإنذارات الكاذبة).
- الصيغ المدعومة: `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`.
- الحد الأدنى الموصى به: **20–50 صورة لكل فئة** (انظر `docs/AI_VALIDATION_GUIDE_AR.md`).

> هذه المجلدات لا تُرفع صورها إلى Git (انظر `.gitignore`). تُحفظ الصور محلياً فقط.
